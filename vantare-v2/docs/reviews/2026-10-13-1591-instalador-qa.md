## Límites que bloquean la integración

- Arranque exitoso por «Abrir Vantare», Inicio/autostart y confirmación live del
  feed: falta cuenta/VM de prueba con SID distinto. El pipe `native-beta` se
  comparte por SID. La UI QA rechaza el SID de origen del builder. El fallo de
  Hub con argumentos inválidos prueba rollback, no arranque exitoso.
- Windows limpio y DPI físicos 125/150/200 %, arrastre y revisión independiente
  siguen pendientes. Se solicitó identificar el entorno; no se crean cuentas,
  no se habilita Sandbox y no se cambia el DPI de Isaac.
- Publisher con clave real, Authenticode, build completo de distribución Release
  y release no se ejecutan en esta QA. Setup y Uninstall sí se construyen en
  Release con el payload Debug QA descrito arriba (`1591-release-setup.log` y
  `1591-merge-build-{a,b}.log`); esto no es una release de la aplicación.
  El builder valida versión, metadatos PE e imports x64; Setup/Uninstall no importan
  VCRUNTIME140. ICU/DirectWrite/D3D son imports del Windows objetivo; esto no
  certifica todavía una máquina limpia.
- #1565/PR #1592 está integrado en la base nightly incorporada localmente.
  Conserva feed/orígenes/sidecars en Downloads; el conflicto del publisher se
  resuelve manteniendo ese contrato y el builder propio. Se conserva su
  corte 0.0.976 por NSIS. #1589 recibe /S; no acredita aprobación de Store.

no se leen secretos. Los datos fixture de todas las generaciones permanecen
