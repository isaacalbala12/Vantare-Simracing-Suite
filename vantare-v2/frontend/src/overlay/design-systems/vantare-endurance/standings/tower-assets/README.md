# Recursos del estudio Redline

Copias binarias de `redline-taste/` (estudio aprobado por Isaac, 2026-09-08),
usadas para reproducir exactamente su HTML. Sin descargas ni dependencias nuevas.

- `tower-reference.png`: imagen original del estudio; se utilizan solamente
  sus sprites de emblemas y el wordmark de la opción anterior. El resto del
  widget se pinta con DOM/CSS; esta imagen no sustituye al renderer.
- `tower-condensed-400.ttf`, `tower-condensed-600.ttf`, `tower-regular.ttf`,
  `tower-bold.ttf`: archivos tipográficos que ya usaba ese HTML, sin alteraciones.

Esta procedencia documenta el prototipo, no certifica licencias nuevas ni
logotipos oficiales. La normalización de assets para distribución debe
conservar su trazabilidad; no se ha autorizado una release de este estudio.
