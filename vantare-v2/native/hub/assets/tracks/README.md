# Circuitos decorativos

Fuente: tracks/tracks.json del contrato R9.3 del Hub r10. Le Mans: OpenStreetMap, ODbL (https://www.openstreetmap.org/copyright). Resto: bacinger/f1-circuits, MIT (https://github.com/bacinger/f1-circuits). No son datos de sesión; el trazado decorativo no acredita una carrera activa. Silverstone también es bacinger/f1-circuits (gb-1948, MIT), simplificado a 134 puntos. Qatar usa el trazado de Losail. Sebring y Road Atlanta no tienen fuente libre en el repositorio: se quedan sin dibujo.
