# ISA-1399 · prueba visual del sidebar

Las cuatro capturas proceden del harness Orbit con componentes productivos a
1920×1080 y 1920×900. Las variantes Grises clara e Iris oscura fuerzan los
atributos del tema para comprobar los tokens del rail y la columna. El harness
no representa datos de cuenta ni certifica persistencia o interacción Wails.

El ejecutable Wails de esta rama se compiló con la configuración local
autorizada y arrancó en Windows. Queda pendiente la valoración visual de Isaac
en esa ventana antes de cualquier integración.
