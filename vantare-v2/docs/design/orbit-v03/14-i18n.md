# 14 · Catálogo i18n (claves y cadena en `es`)

Convención: `hub.<sección>.<bloque>.<clave>`; plurales con la API de plurales (`_one/_other`); interpolación `{{n}}`. Los ids, nombres de series/circuitos/widgets, enums y teclas **no** se traducen.
