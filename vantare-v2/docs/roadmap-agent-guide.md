# Guía para agentes: roadmap público

El contenido del roadmap se edita visualmente en el Hub y se publica por Owner. No se mantiene un archivo de planificación pública en Git ni se genera un JSON para la app.

Antes de cambiar código, consulta la tarea Notion, el handoff vivo y [mantenimiento del roadmap](roadmap-maintenance.md). Un cambio de contenido público lo decide Isaac y se realiza desde la pantalla del Roadmap: guardar borrador, revisar y publicar. No deduzcas que una tarea completada se publica automáticamente.
