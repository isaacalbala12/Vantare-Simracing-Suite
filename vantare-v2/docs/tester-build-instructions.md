# Instalar y probar una build de Vantare

Vantare se desarrolla para Windows 10/11 con WebView2. Las builds de desarrollo y las del canal público tienen alcances distintos. Esta guía no anuncia que la beta pública reiniciada esté disponible.

1. Usar la release y el canal indicados para tu prueba. Comprobar versión y notas de esa entrega antes de descargar el instalador o paquete Windows.
2. Conservar una copia de los perfiles que necesites antes de sustituir la instalación. Seguir las instrucciones del artefacto elegido; no reutilizar un archivo de otra versión.
3. Abrir la app y comprobar el número de versión. Si Windows o el instalador muestran un aviso, verificar procedencia y notas del artefacto; no asumir que todos están firmados o sin firmar.
4. Acceder a la cuenta según el flujo que muestre esa build. Los accesos Nightly/Testers dependen de los permisos de la cuenta.
5. Crear un perfil de prueba en Studio. Sin simulador, la fuente puede aparecer desconectada; para validar live, iniciar Le Mans Ultimate y entrar en sesión.
6. Probar el cambio solicitado y anotar resultado esperado, resultado observado y pasos para repetirlo.
